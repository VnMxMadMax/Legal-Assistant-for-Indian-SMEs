## 📝 RECORDING TIPS

1. **Before Recording:**
   - Have your OpenAI API key ready
   - Prepare a sample contract file
   - Zoom browser to 110-125% for visibility

2. **During Recording:**
   - Speak slowly and clearly
   - Pause 1-2 seconds when clicking tabs
   - Keep movements smooth

3. **Post-Production:**
   - Add captions if possible
   - Trim any loading delays
