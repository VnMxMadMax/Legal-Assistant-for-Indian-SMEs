## 📝 RECORDING TIPS

1. **Before Recording:**
   - Have OpenAI API key ready
   - Prepare a sample contract
   - Zoom browser to 110-125%

2. **During Recording:**
   - Speak slowly, pause when clicking tabs
   - Keep movements smooth

3. **Post-Production:**
   - Add captions if possible
   - Trim loading delays
